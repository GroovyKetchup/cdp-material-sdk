# 02 - 创建组件包并注册

组件包是 CDP 识别和加载组件的发布单元。一个组件包可以包含 1 个或多个组件。

---

## 适用场景

- 你要创建新的组件包。
- 你已经有组件包，要往里面新增组件。
- 你需要理解 `EngineComponentPackage` 和 `EngineComponentPlugin` 的关系。

---

## 核心模型

```text
React Component + ComponentManifest
        ↓
EngineComponentRegistration
        ↓
EngineComponentPackage
        ↓
EngineComponentPlugin.install(api)
        ↓
api.registerPackage(pkg)
```

关键类型：

```ts
import type {
  EngineComponentPackage,
  EngineComponentPlugin,
  EngineComponentRegistration,
} from 'cdp-material-sdk/portable';
```

---

## 创建组件包

```ts
import type { EngineComponentPackage } from 'cdp-material-sdk/portable';
import { MyButton } from './components/MyButton';
import { myButtonManifest } from './components/MyButton/manifest';

export const myPackage: EngineComponentPackage = {
  id: '@acme/cdp-components',
  version: '1.0.0',
  components: [
    {
      manifest: myButtonManifest,
      component: MyButton,
    },
  ],
};
```

字段说明：

| 字段 | 说明 |
|------|------|
| `id` | 组件包唯一标识，建议与 npm 包名一致 |
| `version` | 组件包版本 |
| `components` | 组件注册列表，每项包含 `manifest` 和 React 组件 |
| `compatibility` | 可选，用于声明 SDK 或引擎版本兼容范围 |

---

## 创建插件入口

```ts
import type { EngineComponentPlugin } from 'cdp-material-sdk/portable';
import { myPackage } from './package';

const plugin: EngineComponentPlugin = {
  id: myPackage.id,
  version: myPackage.version,
  compatibility: myPackage.compatibility,
  install: (api) => {
    api.registerPackage(myPackage);
  },
};

export default plugin;
```

建议优先使用 `api.registerPackage(pkg)`，而不是逐个调用 `api.registerComponent()`。这样更利于版本管理和卸载回滚。

## 往已有组件包新增组件

这是团队协作中最常见的场景。

### 1. 新建组件目录

```text
src/components/UserCard/
├── index.tsx
└── manifest.ts
```

### 2. 导出组件注册项

```ts
import type { EngineComponentRegistration } from 'cdp-material-sdk/portable';
import { UserCard } from './index';
import { userCardManifest } from './manifest';

export const userCardRegistration: EngineComponentRegistration = {
  manifest: userCardManifest,
  component: UserCard,
};
```

### 3. 加入组件包清单

```ts
import type { EngineComponentPackage } from 'cdp-material-sdk/portable';
import { myButtonRegistration } from './components/MyButton/registration';
import { userCardRegistration } from './components/UserCard/registration';

export const myPackage: EngineComponentPackage = {
  id: '@acme/cdp-components',
  version: '1.1.0',
  components: [
    myButtonRegistration,
    userCardRegistration,
  ],
};
```

### 4. 更新版本

新增对外组件时，建议更新组件包版本。团队可以按语义化版本约定：

| 变更 | 建议 |
|------|------|
| 新增组件 | minor |
| 修复组件内部 bug | patch |
| 删除组件或修改已有组件 `type` | major |

---

## 命名建议

| 对象 | 建议 | 示例 |
|------|------|------|
| 包 id | 与包名一致 | `@acme/cdp-components` |
| 组件 type | 带组织前缀 | `acme.UserCard` |
| 组件目录 | PascalCase | `UserCard` |
| manifest 变量 | camelCase | `userCardManifest` |
| registration 变量 | camelCase | `userCardRegistration` |

---

## 自检

每次新增或修改组件包后，至少检查：

- [ ] `components` 中每个组件都有唯一 `manifest.type`。
- [ ] `plugin.id` 与 `package.id` 一致。
- [ ] `plugin.version` 与 `package.version` 一致。
- [ ] 每个 manifest 通过 `validateManifest()`。
- [ ] 新增组件已加入 `EngineComponentPackage.components`。
