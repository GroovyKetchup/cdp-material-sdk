# 03 - 开发最小可运行组件

本文说明如何开发一个最小可被 CDP 宿主加载、渲染和识别的组件。

---

## 适用场景

- 你要从零开发一个 CDP 组件。
- 你要往已有组件包里新增组件。
- 你要先跑通最小闭环，再按需添加事件、动作、状态、插槽或数据能力。

---

## 最小输出

一个最小组件通常包含：

```text
MyText/
├── index.tsx
└── manifest.ts
```

---

## 1. 编写 React 组件

```tsx
import { forwardRef } from 'react';
import type { BaseUIProps } from 'cdp-material-sdk/portable';

export interface MyTextProps extends BaseUIProps<HTMLDivElement> {
  text?: string;
}

export const MyText = forwardRef<HTMLDivElement, MyTextProps>((props, ref) => {
  const { text = 'Hello CDP', slotProps } = props;

  return (
    <div {...slotProps?.root} ref={ref}>
      {text}
    </div>
  );
});

export default MyText;
```

关键要求：

- 使用 React 组件或 React wrapper。
- 推荐使用 `forwardRef`，后续可扩展 actions 和 state。
- 接收 `BaseUIProps`。
- 将 `slotProps.root` 透传到真实 DOM 根节点。

---

## 2. 编写 ComponentManifest

```ts
import {
  COMPONENT_CATEGORY,
  INJECT_PATH_SLOT_PROPS,
  type ComponentManifest,
} from 'cdp-material-sdk/portable';

export const myTextManifest = {
  type: 'acme.MyText',
  meta: {
    title: '文本',
    category: COMPONENT_CATEGORY.GENERAL,
    description: '一个最小文本组件',
  },
  engine: {
    render: {
      injection: {
        rootPath: INJECT_PATH_SLOT_PROPS,
      },
    },
  },
  props: {
    type: 'object',
    properties: {
      text: {
        type: 'string',
        title: '文本内容',
        default: 'Hello CDP',
      },
    },
  },
  usage: {
    tips: ['适合展示短文本'],
    warnings: ['不建议用于长篇富文本'],
  },
} satisfies ComponentManifest;
```

最小必填项：

| 字段 | 说明 |
|------|------|
| `type` | 组件唯一标识 |
| `meta.title` | 组件显示名 |
| `meta.category` | 组件分类 |

推荐声明：

| 字段 | 说明 |
|------|------|
| `props` | 可配置属性的 JSON Schema |
| `engine.render.injection.rootPath` | 宿主根节点属性注入位置 |
| `usage.tips` / `usage.warnings` | 面向 AI 与设计器的使用提示，让组件从一开始就具备可读语义 |
| `meta.description` | 面向使用者的一句话说明 |

## 3. 加入组件包

```ts
import type { EngineComponentPackage } from 'cdp-material-sdk/portable';
import { MyText } from './components/MyText';
import { myTextManifest } from './components/MyText/manifest';

export const myPackage: EngineComponentPackage = {
  id: '@acme/cdp-components',
  version: '1.0.0',
  components: [
    {
      manifest: myTextManifest,
      component: MyText,
    },
  ],
};
```

## 自检

```ts
import { validateManifest, printValidationResult } from 'cdp-material-sdk/portable';
import { myTextManifest } from './components/MyText/manifest';

const result = validateManifest(myTextManifest);
printValidationResult(result);

if (!result.valid) {
  process.exitCode = 1;
}
```

完成标准：

- [ ] `validateManifest()` 没有 error。
- [ ] 组件能被加入 `EngineComponentPackage.components`。
- [ ] 组件根 DOM 能收到 `slotProps.root`。
- [ ] 没有直接依赖宿主内部模块。
